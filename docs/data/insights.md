## CNPJ

### Calculando faixas das faixas de idade da empresa
Melhor para análise estatística: usei os quantis para evitar bins vazios; reduzir skew;

Idade empresa melhor usar quartis mesmo  porque:
distribuição tende a ser razoável;
bins ficam equilibrados;
ótimo para clusterização.

### Calculando faixas das faixas de capital socail 
melhor usar bins logarítmicos geralmente tem distribuição de Pareto

Porque:

idade:
    distribuição menos extrema;
    quartis fazem sentido.
capital social:
    distribuição MUITO enviesada;
    quartis escondem diferenças reais;
    escala log fica muito melhor.
