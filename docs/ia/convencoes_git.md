# Convenções Git

## Objetivo

Padronizar:

- histórico
- revisão
- rastreabilidade
- colaboração com IA

---

## Formato de Commit

tipo: descrição curta

Exemplos:

feat: adiciona estimador razão
fix: corrige clusterização ward
docs: adiciona hipótese do artigo
refactor: simplifica ingestão TSE

---

## Tipos Permitidos

| Tipo | Uso |
| feat | nova funcionalidade |
| fix | correção |
| refactor | refatoração |
| docs | documentação |
| test | testes |
| chore | tarefas auxiliares |

---

## Regras

- commits pequenos
- commits atômicos
- evitar múltiplos assuntos no mesmo commit
- mensagens claras e objetivas
