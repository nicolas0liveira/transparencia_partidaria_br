# Organização de Notebooks

## Objetivo

Os notebooks devem servir para:

- exploração
- validação estatística
- visualização
- prototipação

Não devem concentrar:

- regras de negócio complexas
- lógica reutilizável
- pipelines definitivos

## Estrutura Interna

Todo notebook deve conter:

1. objetivo
2. hipótese
3. preparação
4. análise
5. conclusão parcial

---

## Regras

Evitar:

- notebooks gigantes
- células excessivamente longas
- múltiplos objetivos no mesmo notebook

Persistir:

- datasets intermediários
- tabelas analíticas
- imagens analíticas
- resultados importantes
